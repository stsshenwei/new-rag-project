# Data Processor

Use this skill when the user asks to organize evidence into a table, checklist, comparison, normalized field list, or structured summary.

## Method

1. Confirm the fields implied by the user question.
2. Use only retrieved evidence.
3. Mark missing fields as unknown instead of inventing values.
4. Keep the output compact and easy to scan.
